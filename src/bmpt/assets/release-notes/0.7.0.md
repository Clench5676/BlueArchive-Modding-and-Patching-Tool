## What's New

- **Switch Chibi:** dress a student's 3D chibi in any outfit of the student's own or of another student, all listed at once and searchable.
- **Optimize Physics:** save a switched chibi as a separate copy with steadier skirts, hair and ribbons.
- **Chibi actions:** play the student's battle animations, retreat and knockdown included, from a grouped action bar.
- **Game updates:** Mods are checked before the first screen after a game update, and the Mods to Update list can be reopened from Settings.
- **Portrait repair:** portrait Mods broken by a game update are repaired automatically, with a before-and-after comparison.
- **Memorial lobby camera:** frame a memorial lobby your own way and keep each framing in an album as a lobby choice.
- **Student Hall:** select a portrait by its visible outline and give each one its own toolbar, size and quick alt or Mod swap.
- **ZIP import:** import Mods straight from ZIP archives.
- **Tasks:** a Tasks panel shows the jobs that are queued and running.
- **Error codes:** every failure message carries an error code to quote in reports.

## Changes

- On the Global client (Steam), Mods are turned on and off by swapping the game's catalog file instead of each resource file.
- The App opens its first screen sooner, and turning Mods on or off is faster.
- Popups, buttons and lists across the App follow the game's own look.
- Your data moves to a new format at the first start, and the old files are kept.

## Fixes

- Files from a Mod always stay inside their output folder.
- A damaged state or settings file no longer loses the Mod library, and each Mod updates as a whole.
- Mods applied after a game update no longer make the game report an abnormal client.
- Windows no longer fails now and then to apply a Mod because the game file is in use.
- macOS keeps the top bar moving the window and the window buttons in place after popups and fullscreen.

## 新功能

- **切换3D模型：**给学生的3D模型换上本人或其他学生的任意服装，所有服装一次列出，可搜索。
- **优化物理效果：**把换装后的3D模型另存为一份裙摆、头发和发带更稳定的副本。
- **3D模型动作：**在分组的动作栏里播放学生的战斗动画，包括撤退和被击倒。
- **游戏更新：**游戏更新后进入首页前先检查Mod，「需要更新的Mod」列表可在设置中再次打开。
- **立绘修复：**被游戏更新破坏的立绘Mod自动修复，并可对比修复前后。
- **记忆大厅镜头：**按自己的想法为记忆大厅取景，每个取景都存进相册，作为大厅的一个选项。
- **学生大厅：**按立绘的可见轮廓选中，每个立绘有自己的工具栏和大小，可快速切换换皮或Mod。
- **ZIP导入：**可以直接从ZIP压缩包导入Mod。
- **任务：**新增任务面板，列出排队中和进行中的任务。
- **错误代码：**每条失败提示都带错误代码，反馈时可直接引用。

## 变更

- 国际服（Steam）启用和停用Mod改为替换游戏的目录文件，不再逐个替换资源文件。
- App更快进入首页，启用和停用Mod也更快。
- 全App的弹窗、按钮和列表都改用游戏自己的样式。
- 首次启动时数据转换为新格式，旧文件保留不动。

## 修复

- Mod中的文件始终留在输出文件夹内。
- 状态或设置文件损坏不再丢失Mod库，每个Mod整体更新。
- 游戏更新后应用的Mod不再让游戏报客户端异常。
- Windows上应用Mod时不再偶尔因游戏文件被占用而失败。
- macOS上弹窗和全屏之后，顶栏仍能拖动窗口，窗口按钮也保持原位。
