## What's New

- **Switch 3D Model:** dress a student's 3D model in another outfit, the student's own or another student's; every outfit is listed at once and can be searched
- **Game updates:** Mods are checked against a game update before the first screen; the affected ones are listed, and portrait Mods the update broke are repaired with a before-and-after preview
- **Memorial lobby camera:** frame a memorial lobby and keep the framing as a choice of its own
- **Student Hall:** select a portrait by its visible outline; each portrait gets its own toolbar, size and quick skin swap
- **Import Mods:** a refused row says why and which files are missing; Import opens from a student's add buttons
- The top bar and bottom menu enter like the game's lobby, and stay hidden in fullscreen and the camera until the pointer reaches the window's edge
- Memorial lobby dialogue in the game's own speech balloon

## Changes

- Popups, buttons, chips and lists follow the game's own design throughout the App
- Writing Mods onto files that a not yet tested game version changed asks for confirmation first
- The student roster and Switch 3D Model open faster; thumbnails are kept across game updates
- Failure messages carry an error code for reports

## Fixes

- Files from a Mod always stay inside their output folder
- Safer Mod library: a damaged state or settings file no longer loses the library, a failed library move can be retried, and each Mod updates as a whole
- macOS: the top bar moves the window again after a popup or fullscreen, the window buttons stay on wide or second displays, and the game's pointer no longer flickers to the system pointer
- Escape and keyboard focus stay within the topmost popup
- Many text fit, alignment and layout details

## 新功能

- **切换 3D 模型：** 给学生的 3D 模型换上其他服装，可以是本人的，也可以是其他学生的；所有服装一次列出，可搜索
- **游戏更新：** 游戏更新后，进入首页前先检查 Mod；列出受影响的 Mod，被更新破坏的立绘 Mod 自动修复，可对比修复前后
- **记忆大厅镜头：** 为记忆大厅取景，并把取景保存为单独的选项
- **学生大厅：** 按立绘的可见轮廓选中；每个立绘有自己的工具栏，可单独调整大小、快速换皮
- **导入 Mod：** 被拒绝的条目会说明原因和缺少的文件；可从学生的添加按钮直接打开导入
- 顶栏和底栏按游戏大厅的方式进场；全屏和拍摄时隐藏，指针移到窗口边缘时出现
- 记忆大厅台词使用游戏自己的对话气泡

## 变更

- 弹窗、按钮、标签和列表全面采用游戏自身的设计
- 往尚未测试的游戏新版本改动过的文件写入 Mod 前，先确认
- 学生名单和切换 3D 模型打开更快；游戏更新后保留已有的缩略图
- 失败提示附带错误代码，便于反馈

## 修复

- Mod 中的文件始终留在输出文件夹内
- Mod 库更安全：状态或设置文件损坏不再丢失 Mod 库，Mod 库迁移失败可以重试，每个 Mod 整体更新
- macOS：弹窗或全屏后顶栏可再次拖动窗口；宽屏或第二块屏幕上窗口按钮不再消失；游戏指针不再闪成系统指针
- Esc 和键盘焦点只作用于最上层的弹窗
- 修复多处文字适配、对齐和布局细节
