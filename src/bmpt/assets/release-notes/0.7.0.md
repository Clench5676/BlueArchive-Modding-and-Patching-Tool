## What's New

- **Switch Chibi:** dress a student in another student's model already in the game.
- **Chibi actions:** more battle animations to play.
- **Memorial lobby camera:** set your own camera position for a memorial lobby.
- **Mod ZIP files:** import and export Mods as ZIP archives.
- **Tasks:** a Tasks panel shows the jobs that are queued and running.
- **Error codes:** every failure message carries an error code to quote in reports.
